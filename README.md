# Moving Sale website

A simple bilingual (English / Mexican Spanish) moving-sale site. Listings come from a Google Sheet that's fed by a Google Form.

- **Setup instructions:** [SETUP-GUIDE.md](SETUP-GUIDE.md)
- **Settings** (WhatsApp number, meet-up areas, payment, sheet link): `config.js`
- Plain HTML/CSS/JS, no build step, hosted on GitHub Pages. Until `sheetCsvUrl` is set, the site shows sample items from `sample-data.js`.
